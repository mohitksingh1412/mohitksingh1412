## 🎓 Ph.D. Research | Computer Vision & Image Restoration

**Doctor of Philosophy (Ph.D.) in Computer Engineering**  
Malaviya National Institute of Technology (MNIT), Jaipur

My doctoral research focused on single-image dehazing, visibility enhancement, illumination modeling, and deep multi-scale feature representations.

**Research Highlights:**

- **Luminance-Based Image Restoration:** Improved Dark Channel Prior (DCP) transmission estimation using YCbCr color space to mitigate halo artifacts.
- **Retinex-Based Model-Independent Dehazing:** Developed illumination-reflectance separation approaches with dynamic color correction for nighttime and non-uniform haze.
- **DSA-Net:** Designed a Dense Spatially-Weighted Attentive Residual Network for direct haze-layer learning using Residual-Inception Attention (RIA).
- **Multi-Scale Feature Fusion:** Explored coarse-to-fine deep learning architectures integrating channel and pixel attention for challenging real-world weather conditions.

**Research Interests:**

`Image Dehazing` `Low-Light Enhancement` `Image Restoration` `Object Detection` `Re-Identification` `Deep Learning` `Attention Mechanisms`
